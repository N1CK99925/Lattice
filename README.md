# Lattice



Lattice is a tool that allows you to create a graph of your codebase which helps agents with context, using tree sitter to parse it.


./internal/repository/ folder is responsible for understanding the repository itself

./internal/parser/ is where the tree sitter parser is located

./internal/models/ is where models like ID, name, type, file etc are located

./internal/git/ is where git related functions are located
